# E-commerce-GMV-analysis
Multi-platform e-commerce GMV attribution analysis using multiplicative decomposition (GMV = Impression × CTR × CVR × ARPU), with dimensional drill-down across platform / category / city, Shapley Value attribution, and automated HTML report + Feishu card JSON output.

## Dataset
The dataset used in this project is a simulated multi-platform e-commerce dataset sourced from **Alibaba Cloud Tianchi**, modelling the business processes of major Chinese e-commerce platforms (Taobao, JD.com, Douyin, etc.)
